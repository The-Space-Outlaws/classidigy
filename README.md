# How to play
First you need to select the version you want, then you're taken to the login page, where you can load a character save file you have on your device, offline mode makes a randomized wizard and new wizard lets you design your wizard.
When you're done playing, go to settings, other or network depending on the version you have, and click save character and it downloads a save file to your device!
1-30-0 you ask? Well, you may notice buttons like, "New user", "Login", "Load local save" and "Load file save".
New User doesn't work yet.
Click login to enter offline mode with a generated randomized wizard! 
Load file save allows you to load a file from your device.
Load local save allows you to choose a wizard you saved on your browser!
